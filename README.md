# architechture

## 建筑论文全流程指导

一个覆盖选题、材料阅读梳理、理论建构、论文框架组织和最终写作的中文skill。参考杨宇振的公开研究方法，提供引导、教学、判断和修改建议；不代表本人或所属机构的授权与认可。

### 开始使用

完整说明见 [使用指南](USER_GUIDE.md)。在能够加载本技能的助手中说：

> 启动论文全流程指导。我目前处于【阶段】，研究问题是【问题】，已有【材料】，卡在【困难】。这次请帮我【任务】，保留【限制】。

### 内容

- SKILL.md：运行入口与阶段路由。
- references/workflow.md：五阶段工作规则。
- references/critical-review.md：严肃审阅、修改顺序及证据边界。
- references/public-methods.md：公开来源及实际阅读范围。
- USER_GUIDE.md：材料准备、提问示例、接续与修改方法。

### 范围与验证

这是单独整理的公开资料版本，无私人会议、指导转写、论文原件、个人路径或其测试底稿。五阶段流程与审阅分级为工具设计，未声称由教授本人命名。本公开版尚未独立验证全流程教学效果；不继承本地其他版本的测试成绩。

编制流程参考 [女娲·Skill造人术](https://github.com/alchaincyf/nuwa-skill)。公开来源链接留在参考文件中，不分发论文全文。

### 下载与加载

下载本仓库后，将包含 `SKILL.md`、`USER_GUIDE.md` 和 `references` 的目录整体作为技能加载；目录名称可设为 `architecture-thesis-guide`。不同助手的安装入口不同，请按所用工具的技能安装方式操作。
