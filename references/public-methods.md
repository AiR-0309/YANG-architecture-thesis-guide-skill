# 公开方法与来源

以下为方法概述，不是对全部著作的完整提炼。本文件仅介绍公开文献；完整技能另含匿名指导方法及读书会整理稿，去标识处理见PUBLICATION_NOTES.md。

- 杨宇振，《危机应对：理解中国城市化与规划的第三种视角》，2019，79—85页，正文已读。可借鉴检查经验推广范围、解释关系及尺度条件的方法；不能要求所有题目采用同一解释。[官方PDF](https://www.upi-planning.org.cn/Files/hjcsgh/MagazinePDF/9f2ac227-ffa6-4b05-85e2-738392725174.pdf)
- 《生产新空间：近代中国建市划界、冲突及其意涵》，2019，108—117页，正文已读。可借鉴区分技术操作、制度及实际权限，不能凭名称或图示就认为作用已经发生。[官方PDF](https://upforum.wupen.org/Assets/userfiles/files/issues/2019/01/2019-01-13.pdf)
- 《危机中的空间生产——列斐伏尔、康斯坦特与总体都市主义》，2024，71—78页，正文已读。检查理论形成的语境和从理念走向具体实践的条件；文中被引学者的观点和激烈措辞不能全部归给作者。[官方PDF](https://www.upi-planning.org.cn/Files/hjcsgh/MagazinePDF/69ca1436-dfd3-4f2b-b6fc-d13495d2982e.pdf)
- 《多余的写作》，2022-12-31，已读媒体刊载前言与六篇节选，未读其题名列表中所有文章。可借鉴检查数字排行、修饰语与实际内容的距离；虚构故事不用作真实经历。[刊载页](https://www.sohu.com/a/623294562_399447)
- 有方访谈，2014-12-27，问答已读。可借鉴核查提问预设、实践条件与知识边界，不以当时自述判今日能力。[原访谈](https://www.archiposition.com/items/20180525093945)
- 建筑档案访谈，2020-03-31，全文已读。可借鉴从日常观察反观问题、联系综合视野与专业工作的思路。访谈经过编辑，不据此还原完整口语。[原访谈](https://www.jzda001.com/index/index/details?id=2094&type=1)
